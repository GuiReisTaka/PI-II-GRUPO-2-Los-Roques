The Revenge of Grigori é um jogo educacional 2D desenvolvido como projeto acadêmico, com foco no ensino de Química, especialmente conceitos relacionados a misturas e transformações químicas.
O jogador acompanha a jornada de Grigori, um mago aprendiz expulso por seu mestre por ser considerado fraco. Determinado a se tornar mais poderoso, Grigori aprende novas magias por meio de fenômenos químicos reais, como reações endotérmicas, exotérmicas e mudanças rápidas de estado físico.
  
O jogo busca integrar entretenimento e aprendizagem, apresentando conteúdos científicos de maneira prática, visual e contextualizada dentro da narrativa.
Cada magia: fogo, gelo, raio e plasma, é desbloqueada a partir da combinação de substâncias inspiradas em reações químicas reais, permitindo que o jogador aprenda enquanto avança na história e derrota inimigos.
  
Como Executar o Projeto:  
  1. Instale a biblioteca Allegro 5.  
  2. Abra o projeto no Visual Studio.  
  3. Compile o código fonte.  
  4. Execute o jogo diretamente pela IDE  
  
Controles do Jogo:  
  
  Movimentação:  
    W – Mover para cima  
    A – Mover para a esquerda  
    S – Mover para baixo    
    D – Mover para a direita  
  Ações:  
    Tecla esc - Fecha o jogo  
    Tecla p - Avança os dialogos  
    Botão esquerdo do mouse - lança magia
